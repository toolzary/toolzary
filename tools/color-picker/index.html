Frequently Asked Questions

Everything you need to know about picking colors

HEX is a 6-digit hexadecimal representation of color. For example, #4F46E5 represents a shade of purple/blue.

RGB stands for Red, Green, Blue. Each value ranges from 0 to 255. For example, rgb(79, 70, 229) represents the same color as #4F46E5.

HSL stands for Hue, Saturation, Lightness. Hue is measured in degrees (0-360), Saturation and Lightness are percentages.
